# Bangalore Jewellery Shops

Area-wise directory of jewellery showrooms across Bengaluru.

## Features
- Search by shop, brand, locality, or collection
- Filter by area and jewellery type
- Phone links where published
- Google Maps directions
- Responsive mobile, tablet, and desktop layout
- Page owner label: Ainn

## GitHub Pages
The repository includes a GitHub Actions workflow to publish from `main`. In GitHub, open **Settings → Pages** and confirm **Build and deployment → Source: GitHub Actions**.

## Accuracy note
Store addresses and phone numbers are compiled from published brand store locators and public business listings. Details may change; call the store or check its official locator before visiting. Listings without a published phone number do not display an invented number.

## Sources checked
- Tanishq Bengaluru store locator: https://stores.tanishq.co.in/store-locator/jewellery-stores/city/Bangalore
- Bhima store locator: https://www.bhimagold.com/stores
- Mia by Tanishq store locator: https://www.miabytanishq.com/en_IN/store-locator/find
- Public business listings for individual branches.
